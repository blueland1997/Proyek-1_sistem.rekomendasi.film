# Proyek Sistem Rekomendasi Film Berbasis Chatbot 

Sistem Rekomendasi Film Berbasis Chatbot ini dikembangkan menggunakan dataset TMDB 5000 untuk mengatasi masalah penumpukan pilihan (information overload) melalui antarmuka percakapan bahasa alami yang interaktif. Dengan mengintegrasikan metode Natural Language Processing (NLP) berupa TF-IDF dan Cosine Similarity.

Anggota:
  1. Muhammad Faiz Arsyah Hutabarat (blueland1997)
  2. Muhammad Al Fayyedh Denof (alfayyedhh)
  3. Muhammad Fathan Asyauqi Muntaqo (Pithin)
  4. Muhammad Fikri Hanif (fiqrihanif)
